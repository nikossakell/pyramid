# Pilot study protocol

> Status: outline. Must stay aligned with `docs/dpia.md` and the consent forms:
> any change to how photographs are handled changes all four documents.

## 1. Objectives

Primary: feasibility and logging adherence over 12 weeks.
Secondary: usability (SUS), diet-quality change (KIDMED 2.0), wellbeing (WHO-5),
family nutrition and physical activity environment (FNPA), safety events.

## 2. Design

12-week pilot randomised controlled trial in sports academies, ages 10--16.

### Inclusion
### Exclusion

## 5. What participants are told about photographs

The photograph is prepared and screened on the child's own device, sent only if
it looks like food, recognised on the university server **in memory only**, and
discarded immediately. Only the confirmed dish name is kept. This wording must
match `docs/ephemeral-processing.md`; if that document's claim ever fails, the
consent given here is no longer accurate.
